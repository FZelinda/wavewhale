LAME in WaveWhale

WaveWhale 1.0.1 (build 11) uses LAME 3.100 to encode MP3 audio. Copyright belongs to the LAME Project and its contributors. The app’s Settings include a LAME credit and license. Apple frameworks handle decoding and M4A/WAV output; the optional GPL-licensed MPGLIB decoder is not included in the compiled library.

Exact library source and build files

Includes the encoder source used in this version, Package.swift, the Apple-platform configuration, the complete original LAME 3.100 source archive, source hashes and full license texts. No proprietary application source or compiled app is included in this source package.

Personal library replacement kit

Includes the unencrypted compiled application and tools to build a modified LAME library, replace the bundled dynamic library, and sign it for personal installation. The kit README describes supported environments, signing requirements, limitations and test evidence. It contains no proprietary application source, signing credentials or provisioning profiles.
