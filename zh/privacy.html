波波鲸隐私政策

了解波波鲸如何处理录音、文件和购买信息。

更新日期：2026 年 10 月 1 日

本页内容

适用范围录音与导入文件本地保存与删除免费导出次数购买与 Apple文件分享网站与支持数据管理与联系

适用范围

本政策说明波波鲸 iPhone 与 iPad 应用及本开发者网站如何处理信息。波波鲸通过 GitHub 账号 fzelinda 维护，你可以通过下方支持入口联系维护者。

录音与导入文件

波波鲸在设备本地处理音频和视频。你主动选择导入的文件会复制到应用的本地存储，以便编辑。麦克风权限仅用于录音，你可随时在 iOS 设置中调整。我们不运营媒体上传服务器，不接收你的录音，也不使用它们训练 AI 模型。如果你选择云盘中的文件，文件提供方可能需要先将其下载到你的设备。

本地保存与删除

项目、音频、编辑信息及导出文件保存在应用本地资料库中。删除项目会移除该项目及未被其他项目引用的源媒体；此前导出的文件可能仍然保留。删除应用会移除应用本地资料库。你另存或分享的副本以及设备备份，由你、iOS 或相关服务独立管理。波波鲸不提供自建云同步或云备份，请另行备份重要作品。

免费导出次数

应用在设备钥匙串（Keychain）中保存免费体验状态，以及适用时关联的项目标识，用于防止通过删除项目恢复已使用的免费导出次数。这份本地记录不会发送给我们，不通过波波鲸同步，并且在删除应用后仍可能保留。

购买与 Apple

订阅、首次优惠试用、终身会员购买及付款资料由 Apple 处理。波波鲸在设备上使用 Apple 验证的交易信息，例如商品、有效期与撤销状态，判断可用权益。我们不接收你的银行卡资料。Apple 的 App Store 和支付记录受 Apple 隐私政策约束。

文件分享

当你导出、保存或分享文件到其他应用、服务或个人时，接收方按照自身规则处理其副本。分享过程不会将媒体发送给我们。我们不出售个人信息，应用不含广告 SDK、不使用第三方分析工具，也不要求创建应用账号。

网站与支持

本网站托管在 GitHub Pages。我们没有加入分析脚本、广告追踪器或 Cookie。GitHub 为提供与保护服务，会处理包括 IP 地址在内的技术请求信息，详见 GitHub 隐私声明。如果你通过 GitHub Issues 联系支持，你的 GitHub 资料与留言会公开显示。维护者只将你主动提供的信息用于回复与解决问题，请勿提交敏感内容。平台的保存期限与账号功能由 GitHub 管理；支持讨论可能持续公开，直至你、维护者或 GitHub 按平台允许的方式移除。

数据管理与联系

你可以在 iOS 设置中管理麦克风权限和设备备份，通过 Apple 管理购买，并按上述方式移除应用本地数据。我们没有开发者端账号或媒体数据库可供查询或删除。如果你对主动提交的支持信息有疑问，请通过支持页面联系我们。我们不会有意向儿童索取个人信息。如信息处理方式发生变化，我们会更新本页并修改日期。

通过 GitHub 联系支持 ↗

GitHub Issues 为公开页面，提交问题需要 GitHub 账号。请勿上传私人录音、付款资料或其他敏感信息。
