怎样开始？

从「文件」导入音频，使用麦克风录音，或导入视频并提取其中的音频。在 1.0.1 及后续版本中，视频入口会打开系统照片选择器，并保留「从文件选择视频」选项；应用只能读取你选中的视频。内置巴赫示例可供你先熟悉工具，再处理自己的文件。

可以怎样编辑？

放大波形、选择范围，保留或删除选区，分割或复制片段，并按顺序合并。1.0.1 版本新增随屏幕宽度调整布局的工作台、多轨编排与混音，以及速度和音调控制。「添加音轨」可将音频或视频声音导入新轨，也可移入选中片段。音量、峰值归一化与淡入淡出可用于进一步调整，想回到上一步时可使用撤销。

支持哪些导出格式？

1.0.1 及后续版本支持导出 MP3、M4A 和 WAV，可设置采样率、单声道或立体声，以及 MP3/M4A 的码率或 WAV 的位深。1.0.0 版本支持导出 M4A 和 WAV。导出后通过 iOS 分享面板保存或分享，可导入的媒体格式取决于 iOS 的解码支持。铃声用途是剪辑并导出音频片段；波波鲸不提供 M4R 导出或直接安装系统铃声，需在应用之外通过系统或其他工具设置。

免费体验怎么算？

你可同时完整编辑一个个人项目，不设体验期限，包含一次成功导出。取消或失败不扣次数。成功导出前，删除项目后可以重新开始；成功导出后，删除或重置项目不会恢复次数。内置示例始终免费。

订阅、7 天试用和终身会员

月付、年付与终身会员解锁相同工具，有效权益期间不限项目和导出次数。7 天订阅试用仅在 Apple 确认可享优惠且你确认订阅后开始；若不取消，到期会按 Apple 展示的价格自动续费。它与“不需订阅、不会自动续费的一次免费导出体验”相互独立。终身会员是单次购买，不自动续费。购买终身会员不会自动取消已有订阅，请另行通过 Apple 管理。

恢复购买、取消订阅或申请退款

使用购买时的 Apple 账号，在应用内选择“恢复购买”。在 iOS 设置 → 你的姓名 → 订阅中管理或取消订阅。如需避免续费，请在当前周期或试用结束至少 24 小时前取消。退款由 Apple 通过报告问题页面处理。权益以 Apple 验证的购买状态为准。

录音或播放遇到问题？

请检查 iOS 设置中的麦克风权限、设备剩余存储空间及当前音频输出设备。停止其他使用麦克风的应用后重试。录音或导出期间保持应用打开，排查前请另行保存重要文件。

开源软件与动态库替换

波波鲸 1.0.1 使用 LAME 编码器导出 MP3。你可以在开源软件说明页阅读许可说明，下载本版本精确对应的编码器源码与构建配置，并免费申请供个人使用的动态库替换材料。如需免费获取对应替换包，请通过 GitHub 提交支持问题，注明应用版本和构建号，并说明需要 LAME 替换材料；不需要购买证明。GitHub Issues 为公开页面，请勿提交私人媒体、支付资料或签名凭据。波波鲸原生应用源码不公开。

还需要帮助？

请提供 iPhone 机型、iOS 版本、应用版本与复现步骤。不含个人信息的截图有助于排查；音频问题请先用文字描述，不要上传机密或私人录音。我们可以使用中文或英文回复。

通过 GitHub 联系支持 ↗

GitHub Issues 为公开页面，提交问题需要 GitHub 账号。请勿上传私人录音、付款资料或其他敏感信息。
